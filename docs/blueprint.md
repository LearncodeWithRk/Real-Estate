# **App Name**: HomeView

## Core Features:

- Property Listings Display: Showcase properties with key details, high-quality images, and a direct WhatsApp booking CTA.
- WhatsApp Booking Integration: Enable users to book property viewings directly through WhatsApp via clickable buttons and links.
- Automated WhatsApp Responses: Implement automated responses for initial WhatsApp inquiries and booking confirmations to provide immediate feedback.
- Live Chat Support: Provide live chat support via WhatsApp to answer property inquiries and schedule viewings in real-time.
- Booking Reminders via WhatsApp: Send automated reminders via WhatsApp one day before the scheduled property viewing to reduce no-shows.
- Smart Property Suggestions: AI-powered tool that analyzes user inquiries and suggests relevant properties based on their criteria in the WhatsApp chat.

## Style Guidelines:

- Primary color: Deep blue (#293B5F) to convey trust and reliability in the real estate business.
- Background color: Light gray (#F0F4F8), offering a clean and professional backdrop that doesn't distract from property listings.
- Accent color: Soft gold (#A6937A) to highlight calls to action, such as booking buttons, and add a touch of sophistication.
- Body font: 'PT Sans', a versatile sans-serif for a modern yet approachable feel; for both headlines and body text.
- Use clean and simple icons to represent property features and amenities.
- Employ a grid-based layout for property listings to ensure a consistent and visually appealing presentation.
- Use subtle transition animations when navigating between property listings and details.
